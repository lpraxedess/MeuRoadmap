# Fase 07 — PAM

[← Início](../README.md) · [Painel](../docs/progresso/painel.md)

> **Objetivo:** proteger contas privilegiadas, controlar elevação e reduzir o impacto de credenciais administrativas comprometidas.

## Rota principal

1. **Estude:** [Conceitos](01-Conceitos/README.md).
2. **Pratique:** [Prática](03-Pratica/README.md).
3. **Aplique:** [Laboratórios](04-Laboratorios/README.md).
4. **Explique:** descreva o ciclo de uma sessão privilegiada segura.
5. **Valide:** execute `roadmap.ps1 validar`.

## 🎯 Validação final

1. O que diferencia uma conta privilegiada de uma conta comum?
2. Como reduzir privilégio permanente?
3. Que controles protegem credenciais administrativas?
4. Como investigar uma sessão privilegiada suspeita?
5. Quais evidências demonstram que o uso privilegiado foi controlado?
