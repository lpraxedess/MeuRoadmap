# 05 — Controle de Acesso

[← Voltar](04-Sessoes.md) · [🏠 Início](../../README.md) · [Próximo →](06-Decisao-de-Acesso.md)

> **Objetivo profissional:** escolher e justificar mecanismos de controle de acesso conforme o contexto do negócio.

## 🎯 O que dominar

- RBAC
- ABAC
- policy-based access
- claims-based access
- scope-based access
- context-aware access

## 🧠 Você precisa conseguir

- explicar o princípio de cada modelo
- escolher um modelo para um cenário simples
- explicar vantagens e limitações
- reconhecer quando uma role está ficando excessivamente ampla

## 🛠️ Prática guiada

Compare dois cenários:

**Cenário A:** sistema interno com funções estáveis.

**Cenário B:** API com regras baseadas em departamento, localização e sensibilidade do recurso.

Para cada um, escolha o modelo predominante e justifique.

## 🏢 Cenário profissional

Uma empresa possui centenas de roles quase idênticas. Identifique os sinais de role explosion e proponha uma estratégia de simplificação.

## 🎤 Pergunta de entrevista

> Quando RBAC é suficiente e quando você precisaria de atributos ou contexto?
