# Certificações IAM

## Estratégia

Certificações não substituem experiência prática.

A recomendação será baseada nas fases concluídas.

## Trilha principal

| Ordem | Certificação | Momento |
|---|---|---|
| 1 | Microsoft SC-300 | Após consolidar Microsoft Identity / Access |
| 2 | Certificação IGA | Após domínio de IGA |
| 3 | Okta Professional | Após Access Management |
| 4 | CyberArk / PAM | Após PAM |
| 5 | AWS Security | Após Cloud IAM |
| 6 | Google Cloud Security | Após GCP IAM |
| 7 | CISSP | Nível avançado / liderança |

## Regra

Não estudar para uma certificação apenas porque ela existe.

Primeiro:

**Conhecimento → Lab → Projeto → Revisão → Certificação**
