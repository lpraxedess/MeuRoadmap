# 01 — Fluxos de autenticação e autorização

[← Conhecimentos](README.md) · [🏠 Fase](../README.md)

## 🎯 Objetivo

Ser capaz de desenhar e explicar o caminho completo de uma autenticação até a autorização do recurso.

## 📚 Domine

- browser/client → IdP → aplicação → API → recurso
- redirect e callback
- sessão
- token de acesso
- token de identidade
- resource server
- scopes e claims
- validação e expiração

## 🧪 Prática

Desenhe um fluxo OIDC e um fluxo OAuth 2.0, identificando quem autentica, quem emite o token e quem autoriza.
