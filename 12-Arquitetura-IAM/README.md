# 12 — Arquitetura IAM

**Missão:** integrar identidade, autenticação, autorização, governança, privilégio, cloud e segurança em uma arquitetura coerente.

## 1. ESTUDAR

Domine IdP, diretórios, federation, IGA, Access Management, PAM, Cloud IAM, CIAM, protocolos, observabilidade, disponibilidade, resiliência e recuperação.

**Modelo mental:** `Identidade → Diretório/IdP → Protocolos → Policies → Acesso → Governança → Detecção → Resposta`.

## 2. PRATICAR

Desenhe uma arquitetura empresarial contendo workforce, aplicações, diretórios, IdP, IGA, PAM, cloud, CIAM quando aplicável e observabilidade.

## 3. APLICAR

Receba um cenário empresarial e identifique componentes, fluxos, trust boundaries, riscos, controles, dependências e pontos de falha.

## 4. EXPLICAR

Sem consultar, defenda cada componente e explique por que ele existe.

## 5. TESTAR

1. Quais componentes uma arquitetura IAM precisa?
2. Como identidade percorre o ambiente?
3. Onde ficam autenticação, autorização e governança?
4. Como integrar IAM corporativo, cloud e aplicações?
5. Como medir segurança, disponibilidade e risco da arquitetura?
