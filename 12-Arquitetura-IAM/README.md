# Fase 12 — Arquitetura IAM

[← Roadmap](../README.md) · [Painel](../docs/progresso/painel.md)

> **Missão:** integrar identidade, autenticação, autorização, governança, privilégio, cloud, detecção e automação em uma arquitetura coerente.

## Rota única
**Estude → Pratique → Aplique → Explique → Teste → Avance**

**Núcleo:** componentes IAM, fluxos, integrações, trust boundaries, controles, observabilidade e operação.

1. Estude o modelo completo.
2. Pratique desenhando uma arquitetura.
3. Aplique requisitos a um cenário empresarial.
4. Explique decisões, riscos e trade-offs.
5. Teste.

### Teste da fase
1. Quais componentes uma arquitetura IAM precisa?
2. Como identidade percorre o ambiente?
3. Onde ficam autenticação, autorização e governança?
4. Como integrar IAM corporativo, cloud e aplicações?
5. Como medir segurança, disponibilidade e risco da arquitetura?

## Gate
- [ ] Estudei o núcleo
- [ ] Desenhei uma arquitetura
- [ ] Apliquei a um cenário empresarial
- [ ] Defendi as decisões
- [ ] Passei no teste e registrei evidência
