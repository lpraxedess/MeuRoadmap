# Progresso

O progresso é controlado automaticamente pelo terminal.

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\roadmap.ps1 agora
```

## Fluxo

1. `agora` — descubra a próxima ação.
2. `concluir` — registre a ação concluída.
3. `teste` — faça a avaliação sem consultar.
4. `aprovar` — libere a próxima fase.
5. `status` — acompanhe o estado.
6. `verificar` — audite a estrutura.

Não é necessário editar checkboxes manualmente.
