# 06 — Access Management

**Missão:** transformar necessidades de negócio em permissões mínimas e auditáveis.

## 1. ESTUDAR

Domine RBAC, ABAC, ReBAC, grupos, roles, atributos, contexto, policies, deny/allow, least privilege e conflito de permissões.

**Modelo mental:** `Sujeito + Contexto + Recurso + Ação → Policy → Decisão`.

## 2. PRATICAR

Crie uma matriz de permissões para três perfis. Comece pelo mínimo necessário e justifique cada exceção.

## 3. APLICAR

Uma aplicação possui permissões excessivas. Identifique roles, heranças, grupos, atributos e regras responsáveis pelo excesso.

## 4. EXPLICAR

Sem consultar, defenda quando RBAC é suficiente e quando atributos/contexto são necessários.

## 5. TESTAR

1. Quando RBAC resolve o problema?
2. Quando atributos e contexto são necessários?
3. Como evitar permissões excessivas?
4. Como investigar uma decisão de acesso?
5. Como tornar uma regra auditável?
