# MeuRoadmap — IAM

Roadmap profissional de IAM com **12 fases**, conduzido por um único fluxo de estudo.

## Como estudar

```text
ESTUDE → PRATIQUE → APLIQUE → EXPLIQUE → TESTE → AVANCE
```

Você não precisa navegar por dezenas de páginas. **Entre na fase atual, execute a missão e só avance quando passar no teste.**

## Agora

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\roadmap.ps1 agora
```

| Comando | Função |
|---|---|
| `agora` | mostra exatamente o que fazer agora |
| `estudar` | mostra o conteúdo da etapa atual |
| `concluir` | registra a etapa atual |
| `teste` | mostra a avaliação da fase |
| `aprovar` | registra a aprovação e libera a próxima fase |
| `status` | mostra o progresso |
| `verificar` | audita a estrutura |

## Regra de avanço

Uma fase só é concluída quando você estudou o núcleo, praticou, resolveu um cenário profissional, explicou o assunto sem copiar e passou no teste.

**O conteúdo aprofundado continua no repositório, mas não bloqueia a trilha principal.**
