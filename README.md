# IAM Career Hub

Hub pessoal de desenvolvimento de carreira para **IAM → Cloud IAM → IAM Engineer**, com foco inicial em Microsoft Identity/Entra ID e expansão para AWS, IGA, PAM, CIEM, automação, Zero Trust e arquitetura.

## Como funciona

O Hub é orientado por dependências. Você não precisa escolher manualmente o próximo assunto:

**Today → Estudar → Praticar → Validar → Evidenciar → Concluir → próxima competência desbloqueada**

O progresso é calculado a partir das competências concluídas. Experiência profissional ou itens do currículo não são considerados concluídos automaticamente.

## Rotina

- 2h/dia de estudo técnico
- 1h/dia de inglês técnico
- laboratório como validação prática
- revisão de conhecimentos já adquiridos
- evidências para portfólio
- certificações como checkpoints

## Estado local

O progresso é salvo no `localStorage`. Use **Settings → Exportar progresso** para backup e **Importar progresso** para restaurar em outro navegador.

## Publicação

O repositório contém workflow de GitHub Pages em `.github/workflows/pages.yml`. Após o Pages estar habilitado no repositório, cada push em `main` publica a aplicação automaticamente.

## Regra de conclusão

Uma competência só deve ser marcada quando você tiver passado pelo fluxo de estudo, prática, validação e evidência aplicável ao item. O Hub deliberadamente não transforma experiência anterior em progresso automático.
