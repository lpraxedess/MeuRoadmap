## ⚙️ Controle local

Use o terminal para descobrir exatamente o próximo item e registrar sua evolução:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\roadmap.ps1 estudar
```

Para marcar um item de validação:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\roadmap.ps1 concluir ".\01-Fundamentos\01-Conceitos\01-Identidade.md" 1
```

> **Regra:** não avance porque leu. Avance quando conseguir explicar, praticar e validar.

<details>
<summary>Como usar o MeuRoadmap</summary>

1. Abra a fase atual.
2. Entre no módulo indicado.
3. Estude um tópico por vez.
4. Faça a prática proposta.
5. Escreva sua explicação com suas próprias palavras.
6. Marque cada validação concluída.
7. Use o terminal para encontrar o próximo item.
8. Registre evidências quando houver laboratório, exercício ou projeto.
9. Só avance de fase quando a validação final estiver concluída.

</details>
