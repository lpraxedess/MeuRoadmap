# MeuRoadmap

> Trilha prática para dominar IAM sem precisar navegar por dezenas de páginas.

## Como usar

Você **não precisa estudar tudo que aparece dentro de uma fase**. O roadmap agora trabalha em modo guiado:

**Estude → Pratique → Aplique → Explique → Valide → Próxima fase**

O terminal aponta somente o próximo passo pendente. Os materiais antigos continuam disponíveis como **aprofundamento**, não como fila obrigatória.

## Agora

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\roadmap.ps1 estudar
```

Depois do estudo:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\roadmap.ps1 validar
```

Quando cumprir o passo indicado:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\roadmap.ps1 concluir
```

Acompanhe:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\roadmap.ps1 status
```

Audite a estrutura:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\roadmap.ps1 verificar
```

## Regra de avanço

Uma fase só termina quando você consegue:

1. explicar o núcleo sem consultar;
2. executar a prática proposta;
3. aplicar o conhecimento em um cenário profissional;
4. responder à validação final.

**Leitura não conta como domínio.**
