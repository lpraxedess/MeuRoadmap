# REGRA DE PROGRESSAO

Nao avancar automaticamente apenas porque o conteudo foi lido.

Uma fase deve ser considerada concluida quando:

- [ ] Conhecimento teorico dominado
- [ ] Pratica realizada
- [ ] Laboratorios realizados
- [ ] Exercicios concluidos
- [ ] Troubleshooting praticado
- [ ] Evidencias documentadas
- [ ] Revisao concluida
- [ ] Capacidade de explicar o assunto em entrevista

---

# REGRA DE CERTIFICACAO

Certificacoes serao recomendadas de acordo com o conhecimento acumulado.

Exemplo:

Fases 01 + 02 + 03 + 04

-> revisar conhecimentos da Microsoft SC-300

-> realizar labs

-> fazer simulados

-> avaliar prontidao

-> decidir pela certificacao

A certificacao nao substitui experiencia pratica.
