# 01 - Conceitos Fundamentais de IAM

## Objetivo

Construir o modelo mental necessário para compreender Identity and Access Management.

## 1. Identidade

Estudar:

- identidade digital
- usuário
- conta
- principal
- sujeito
- recurso
- atributo
- credencial
- entitlement
- privilégio
- identidade humana
- identidade não humana
- service account
- machine identity

### Deve conseguir explicar

- diferença entre identidade e conta
- diferença entre identidade e credencial
- diferença entre usuário, principal e sujeito
- relação entre identidade, recurso e privilégio

## 2. Authentication

Authentication responde:

> Quem é você?

Estudar:

- senha
- MFA
- OTP
- certificado
- biometria
- token
- passkey
- passwordless
- fatores de autenticação
- knowledge factor
- possession factor
- inherence factor

## 3. Authorization

Authorization responde:

> O que você pode fazer?

Estudar:

- permission
- privilege
- role
- policy
- ACL
- scope
- claim
- entitlement

## 4. Modelos de controle de acesso

Dominar:

- DAC
- MAC
- RBAC
- ABAC
- PBAC
- ReBAC

### Prática conceitual

Para cada modelo:

- explicar o funcionamento
- explicar quando utilizar
- explicar vantagens
- explicar limitações
- criar um exemplo corporativo

## 5. Least Privilege

Estudar:

- privilégio mínimo
- excesso de privilégio
- privilege escalation
- privilégio permanente
- privilégio temporário
- just-in-time access
- necessidade de acesso

## 6. Identity Lifecycle

Dominar:

- Joiner
- Mover
- Leaver
- Rehire
- Contractor
- Service Account
- Machine Identity

## 7. Governança

Estudar:

- Access Request
- Access Approval
- Access Review
- Access Certification
- Entitlement
- Ownership
- Segregation of Duties
- Role Engineering
- Role Mining

## 8. Arquitetura IAM

Conhecer:

- Directory
- IdP
- SP
- Federation
- SSO
- Provisioning
- Deprovisioning
- Identity Store
