## 🔁 Como estudar

### Em cada tópico

1. **Estudar** — entender o conceito.
2. **Praticar** — executar a atividade proposta.
3. **Explicar** — escrever com suas próprias palavras.
4. **Validar** — responder sem copiar.
5. **Concluir** — marcar os itens da seção `Validação`.
6. **Avançar** — seguir pelo botão `Próximo →`.

### No terminal

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\roadmap.ps1 estudar
```

O comando encontra o **primeiro item de validação pendente** da fase atual.
