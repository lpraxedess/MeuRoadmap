Não considere um exercício concluído só porque encontrou a resposta na internet.

## 🧠 Nível 3 — Cenários

Resolva sem consultar:

1. usuário com acesso excessivo
2. usuário sem acesso necessário
3. conta órfã
4. funcionário desligado ainda ativo
5. service account com privilégio administrativo
6. conflito de SoD

Para cada cenário, identifique **sintoma → risco → hipótese → controle → resultado esperado**.

- [ ] Resolvi os 6 cenários
- [ ] Justifiquei minhas decisões
- [ ] Registrei os pontos de dificuldade
