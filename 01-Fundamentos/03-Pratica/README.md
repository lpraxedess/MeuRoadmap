# 03 — Prática

[← Conhecimentos](../02-Conhecimentos/README.md) · [🏠 Início](../../README.md) · [Próximo → Laboratórios](../04-Laboratorios/README.md)

> **Objetivo:** transformar conhecimento em decisões que você conseguiria defender em um ambiente corporativo.

## 🗺️ Fluxo

**Entender → Executar → Registrar → Explicar → Validar**

Não avance apenas porque conseguiu copiar uma solução. O objetivo é conseguir justificar a decisão.

## 🧪 01 — Matriz de identidades

**Faça:** crie uma matriz com identidade, tipo, recurso, acesso e justificativa.

**Resultado esperado:** diferenciar identidade humana, não humana e privilegiada e justificar cada acesso.

- [ ] Executei
- [ ] Registrei o resultado
- [ ] Expliquei minhas decisões

## 🧪 02 — RBAC

**Faça:** crie 3 usuários, 3 roles, 3 recursos e permissões diferentes.

**Resultado esperado:** nenhum usuário recebe acesso diretamente quando uma role resolver o problema.

- [ ] Executei
- [ ] Registrei o resultado
- [ ] Expliquei minhas decisões

## 🧪 03 — Least Privilege

**Faça:** crie um cenário com excesso de privilégios, identifique o risco e reduza os acessos.

**Resultado esperado:** cada permissão possui uma justificativa de negócio ou operacional.

- [ ] Executei
- [ ] Registrei o resultado
- [ ] Expliquei minhas decisões

## 🧪 04 — JML

**Faça:** modele Joiner → Mover → Leaver.

**Inclua:** evento, identidade, aprovação, acesso concedido, alteração e remoção.

- [ ] Executei
- [ ] Registrei o fluxo
- [ ] Expliquei o lifecycle

## 🧪 05 — SoD

**Faça:** crie duas funções incompatíveis, como solicitante e aprovador de pagamento.

**Resultado esperado:** explicar o conflito, o risco e como uma regra de SoD impediria a combinação.

- [ ] Executei
- [ ] Registrei o resultado
- [ ] Expliquei o risco
