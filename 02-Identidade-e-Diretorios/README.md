# 02 — Identidade e Diretórios

**Missão:** entender como identidades são armazenadas, organizadas, autenticadas e sincronizadas.

## 1. ESTUDAR

Domine: directory service; LDAP; Active Directory; objetos; atributos; grupos; OUs; DNS; Kerberos; sincronização; federation; contas de serviço e machine identities.

**Modelo mental:** `Identidade → Objeto no diretório → Atributos/Grupos → Autenticação → Aplicação`.

## 2. PRATICAR

Modele um diretório corporativo com usuários, grupos, OUs, contas de serviço e regras de acesso.

## 3. APLICAR

Uma conta de serviço deixou de autenticar. Investigue identidade, segredo/certificado, permissões, DNS, Kerberos/LDAP, expiração e logs.

## 4. EXPLICAR

Sem consultar, explique como uma identidade armazenada no diretório chega até uma aplicação.

## 5. TESTAR

1. Que problema um directory service resolve?
2. Como objeto, atributo, grupo e OU se relacionam?
3. Onde LDAP, DNS e Kerberos entram no fluxo?
4. Como sincronizar identidades mantendo governança?
5. Como investigar uma conta de serviço quebrada?
