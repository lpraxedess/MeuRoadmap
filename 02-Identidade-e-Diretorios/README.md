1. **Estude:** [Conceitos](01-Conceitos/README.md) — diretórios, LDAP, Active Directory, objetos, grupos, DNS/Kerberos, sincronização, contas de serviço e federação.

3. **Aplique:** [Laboratórios](04-Laboratorios/README.md).
