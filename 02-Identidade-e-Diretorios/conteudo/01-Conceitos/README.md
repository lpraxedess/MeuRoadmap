## 🔁 Como estudar cada tópico

1. **Estude** o conteúdo indicado.
2. **Pratique** a atividade.
3. **Explique** com suas próprias palavras.
4. **Valide** sem copiar uma resposta pronta.
5. **Marque** somente o que realmente domina.
6. **Use Próximo →** para continuar.
